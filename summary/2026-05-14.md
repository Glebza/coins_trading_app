# Systematic Trading Framework Summary — 2026-05-14

## Main Direction

We are building a systematic trading framework inspired by Robert Carver’s *Systematic Trading*.

The high-level process is:

```text
Instrument selection
 -> Trading rules / forecasts
 -> Combined forecasts
 -> Volatility targeting
 -> Position sizing
 -> Portfolio construction
 -> Execution / backtesting
```

A Carver-style trading rule should not directly produce `BUY` / `SELL` decisions. It should produce a continuous quantified forecast, usually capped around `-20..+20`. The actual position comes later from forecast strength, volatility targeting, and portfolio rules.

### EWMAC Rule

Implemented Carver-style EWMAC in:

```text
framework/forecasts/ewmac_forecast.py
```

It follows the book:

```text
raw EWMAC = fast EWMA - slow EWMA
vol-adjusted EWMAC = raw EWMAC / std(price changes)
forecast = vol-adjusted EWMAC * forecast scalar
final forecast = cap(forecast, -20, +20)
```

Carver forecast scalar table:

```python
(2, 8): 10.6
(4, 16): 7.5
(8, 32): 5.3
(16, 64): 3.75
(32, 128): 2.65
(64, 256): 1.87
```

The EWMAC rule now preserves continuous capped forecasts. `bucket_forecast()` remains only as an optional helper for human-readable `5`-point buckets.

## Backtest Skeleton

We decided not to reuse old `tests/backtest` directly because it is legacy, Binance/order-oriented, and expects `BUY` / `SELL` / `WAIT` strategies.

Instead, we created a pure Carver-style framework backtest:

```text
glebza/tradeapp/src/framework/backtest/
├── __init__.py
├── engine.py
└── result.py
```

The first version:

```text
klines DataFrame
 -> combined EWMAC forecast
 -> naive position = forecast / 10
 -> return = close pct change
 -> strategy_return = previous_position * return
 -> equity curve
 -> drawdown
 -> summary stats
```

It avoids lookahead by using:

```python
position.shift(1)
```

`BacktestResult` contains:

- `rows`
- `total_return`
- `annualized_return`
- `annualized_volatility`
- `sharpe`
- `max_drawdown`

### 3. Replace Naive Position with Volatility Targeting

Current:

```python
position = forecast / 10
```

Next Carver-style version:

```text
annual cash vol target = capital * target vol
daily cash vol target = annual target / 16
instrument currency volatility = price volatility * block value
volatility scalar = daily cash vol target / instrument currency volatility
position = forecast * volatility scalar / 10
```

### 5. Add Position Inertia

Avoid trading tiny position changes:

```python
if abs(target_position - current_position) < threshold:
    keep current_position
```

This matches Carver’s idea of not issuing adjusting orders unless the current position is materially different from the target.
